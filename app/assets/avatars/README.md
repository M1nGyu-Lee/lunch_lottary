# 점심복권 리뷰 아이콘

이 프로젝트를 위해 이미지 생성 도구로 새로 만든 오리지널 캐릭터 8종입니다.
기존 캐릭터 이미지나 브랜드 로고를 입력 자료로 사용하지 않았습니다.

- 말랑 일러스트: 소풍 카피바라, 마법사 여우, 우주 펭귄, 로봇 병아리
- 하찮은 낙서: 대충 감자, 멍한 개구리
- 픽셀 게임: 도트 모험냥, 도시락 유령

이미지는 투명 배경 PNG이며 앱에 포함되어 오프라인에서도 표시됩니다.
사용자는 제공된 아이콘 ID를 선택하며 아이콘 파일을 서버에 따로 올리지 않습니다.

## 생성 프롬프트 구성

내장 이미지 생성 도구를 사용했습니다. 공통 구성은 투명 배경, 중앙에 캐릭터 한 명,
작은 프로필 크기에서도 구분되는 실루엣, 글자·로고 없음, 기존 캐릭터를 참조하지 않는 새 디자인입니다.

| 파일 | 캐릭터·스타일 지시 |
| --- | --- |
| capybara.png | 민트 목도리와 주먹밥 가방을 든 살구색 카피바라, 부드러운 일러스트 |
| fox.png | 라벤더색 마법사 여우, 부드러운 일러스트 |
| penguin.png | 파란 우주복 펭귄, 부드러운 일러스트 |
| robot.png | 노란 로봇 병아리, 부드러운 일러스트 |
| doodle-potato.png | 어설픈 크레용 선으로 그린 감자 요리사 |
| doodle-frog.png | 삐뚤빼뚤한 선과 멍한 눈을 가진 개구리 낙서 |
